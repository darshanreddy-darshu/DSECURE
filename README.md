
# D-SECURE 🛡️
### Phishing Website Detection System

D-SECURE is a machine-learning-based web application that predicts whether a website URL may be phishing or legitimate.

## 🚀 Live Demo
https://dsecure-1.onrender.com

## ✨ Features
- Web-based URL submission
- Machine learning prediction
- Simple interface for checking URLs
- Flask backend
- Scikit-learn model and vectorizer

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- NumPy
- HTML and CSS
- Gunicorn
- Render

## ⚙️ Run Locally
1. Clone the repository:
   `git clone https://github.com/darshanreddy-darshu/DSECURE.git`
2. Enter the project directory.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the application:
   `python app.py`

## ⚠️ Disclaimer
Predictions are estimates and may be incorrect. Do not rely on this tool alone to determine whether a website is safe.
